# Olist Brazilian E-Commerce Analysis

This repository focuses on analyzing Olist's Brazilian e-commerce data with an emphasis on delivery performance and customer experience.

## Project Goal

The main objective is to explore how orders move from purchase to delivery, identify delays and operational bottlenecks, and understand how customer satisfaction is influenced by service quality, shipping experience, and product performance.

## Key Analysis Areas

- Sales and order trends over time
- Product category performance
- Seller and customer behavior
- Delivery time and logistics efficiency
- Order cancellations and delays
- Customer review sentiment and satisfaction drivers

## Typical Data Sources

This project may involve datasets such as:

- `olist_orders_dataset.csv`
- `olist_order_items_dataset.csv`
- `olist_customers_dataset.csv`
- `olist_products_dataset.csv`
- `olist_sellers_dataset.csv`
- `olist_order_reviews_dataset.csv`
- `olist_geolocation_dataset.csv`
- `olist_order_payments_dataset.csv`

## Recommended Workflow

1. Load the datasets into Python or a notebook environment.
2. Clean and merge the tables using keys such as order ID, customer ID, and seller ID.
3. Analyze order lifecycle metrics such as time to delivery and review scores.
4. Visualize findings with charts and dashboards.
5. Summarize actionable business insights for stakeholders.

## Suggested Tools

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook
- SQL (optional)

## Example Insights to Explore

- Which product categories have the highest sales?
- Which regions have the slowest deliveries?
- Are delivery delays associated with lower review scores?
- Which sellers have the highest customer satisfaction?
- What factors correlate with order cancellations or negative reviews?
